# 語音提詞器

支援中文語音辨識的網頁提詞器，會跟著你說話的位置自動捲動。

## 功能

- **跟著你的語速**：說快就快、說慢就慢，停下來它也停
- **說錯了也不怕**：模糊匹配，念錯字、換詞、跳段、回頭重念都能跟上；脫稿時安靜等待
- **眼神貼近鏡頭**：提詞區在畫面最上方；卡住停頓時，未讀內容會自動往上提
- `# 標題` 分章節，一鍵跳轉
- 語音模式自動壓縮空行
- 長按畫面回到編輯，游標停在你念到的位置
- 固定速度模式、鏡像翻轉（外接硬體提詞器用）
- 鏡頭預覽與錄影下載

## 使用方式

1. 需要 **Chrome** 或 **Edge**（Firefox 不支援語音辨識）
2. Windows：雙擊 `啟動提詞器.bat`；或在資料夾內執行
   ```
   python -m http.server 8765
   ```
   再打開 http://localhost:8765
3. 貼上稿子，按「開始提詞 ▶」，允許麥克風權限

> 麥克風需要 `localhost` 或 HTTPS 才能使用，直接雙擊 `index.html` 開啟可能無法收音。

## 快捷鍵

| 按鍵 | 功能 |
|---|---|
| 空白 | 開始／暫停 |
| ↑ ↓ | 上一行／下一行 |
| ← → | 調整固定速度 |
| + − | 字體大小 |
| Home | 回到開頭 |
| Esc | 回到編輯 |

## 注意

Chrome／Edge 的語音辨識服務在雲端，需要網路連線。稿子本身只存在你的瀏覽器裡，不會上傳。

## 檔案

- `tracker.js`：語音追蹤演算法（中文逐字、英文逐詞的局部對齊）
- `app.js`：介面與互動
- `index.html`、`style.css`：頁面
